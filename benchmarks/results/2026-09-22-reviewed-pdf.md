# 人手確認済みPDFによる検出改善

2026-09-22、利用者が確定したローカル正解データ（48ブロック、41スパン、
review revision 8）で改善前後を比較した。分類・開始位置・終了位置がすべて
一致するものだけを正解とし、範囲が部分一致する予測も誤検出と見逃しに数えた。
実在資料の文字列と正解ファイルは `data/annotation-review/` に保持し、
リポジトリには含めていない。

| 指標 | 改善前 | 改善後 |
| --- | ---: | ---: |
| 完全一致 | 25 / 41 | 41 / 41 |
| 誤検出 | 6 | 0 |
| 見逃し・範囲不足 | 16 | 0 |
| Precision | 80.65% | 100% |
| Recall | 60.98% | 100% |

修正対象は、字間の空白を含む見出しの検出用正規化と原文位置への変換、
姓・名の形態素を用いた名簿欄の氏名補完、役職内の誤検出の除外、地域団体の
名称、丁目と班番号のある地区名の列挙、和暦併記の日付である。
氏名末尾の1文字補完には、周辺に複数の完全な氏名と、姓・名部分に対応する
NER結果があることも必要とした。分類の補正は検出項目の選択より先に行い、
人名を無効にしたときに姓が地名として再び検出されないことも確認した。

検出時に正解ファイルを参照する処理や、実在の氏名・地区名をコードに
埋め込む処理、PII辞書への自動登録は追加していない。辞書を空にした状態で
評価した。

## 検証

- 本番と同じAPIを使ったPDFのアップロード・解析・マスク・ダウンロード。
- 解析された本文とブロックIDが、確認済み正解データに一致すること。
- 出力PDFをpypdfで再抽出し、正解範囲だけを黒塗りした文字列に一致すること
  （抽出時の空白・改行の違いを除く）。
- Popplerで描画した出力を確認し、表の配置と対象外の文字が維持されること。
- 全73テストが成功。
- 既存1,000件の合成評価：GiNZA使用時は正解1,050件、誤検出0、見逃し0を維持。
  ルールのみでは正解1,015件、誤検出0、見逃し35件で既存の基準を維持。
- 新規22件の合成回帰データ：正解27件、誤検出0、見逃し0。
- ライセンス検査：79パッケージで成功。

このPDFと新規合成データは、今回の修正に使用した開発用データであり、
未知の資料に対する独立した精度評価ではない。
