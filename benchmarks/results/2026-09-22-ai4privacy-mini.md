# ai4privacy Mini 日本語ベンチマーク（2026-09-22）

[ai4privacy/pii-masking-mini-10k](https://huggingface.co/datasets/ai4privacy/pii-masking-mini-10k)を
現在のGiNZA＋日本語ルールで測定した。モデルの学習・辞書追加・検出ルールの変更は行っていない。
利用者の指定に従い、日本語を主対象にし、隣接する姓・名は評価用の人名1件にまとめた。

検証用33件では完全一致Recall **14.58%**、F1 **17.95%**、元の全PII文字のマスク率は
**27.59%**。現状の検出器がこのデータのPIIを十分に検出できる結果ではない。
検証用の件数も小さいため、この値を日本語全般の精度保証には使わない。

## データと評価範囲

- 出典: ai4privacy / Copyright © 2026 Ai Suisse SA、CC BY 4.0。
- リビジョン: `7b686c2e7475b02e10e38add1eb54a9f604f4361`。
- 日本語validation 33件・4,834文字、train 300件・52,047文字を別々に評価。
  trainは配布元の学習用splitを評価に用いた参考値であり、今回これを使った学習はしていない。
- 姓・名の結合後、対応タグの正解はvalidation 144件、train 1,514件。
  元注釈はvalidation 233件、train 2,295件をすべて保持。
- アプリ分類に直接対応しない注釈はvalidation 71件、train 611件。
  完全一致・部分一致スコアからは除き、元PIIの文字単位の評価には含めた。
- 原文と文字位置は変更せず、正解からの辞書登録もなし。
  ADDRESSは部品単位、PERSONは隣接姓・名を結合するため、完全一致には注釈粒度の影響がある。
- 実際の配布データを全件検証し、9,990件・30言語・27ラベル・73,186注釈を変換できた。
  アプリの対応タグに変換後の正解は全言語train 42,532件、validation 4,903件。

詳しい対応表、対応外タグ、利用条件と再実行コマンドは
[取り込み・評価の手順](../datasets/ai4privacy-mini.md)を参照。

## 精度

| 指標 | validation（主結果） | train（参考） |
| --- | ---: | ---: |
| 文書数 | 33 | 300 |
| 評価用の正解タグ数 | 144 | 1514 |
| 元の全注釈数 | 233 | 2295 |
| 完全一致 TP / FP / FN | 21 / 69 / 123 | 213 / 625 / 1301 |
| 完全一致 Precision | 23.33% | 25.42% |
| 完全一致 Recall | 14.58% | 14.07% |
| 完全一致 F1 | 17.95% | 18.11% |
| 部分一致 Recall | 34.72% | 34.08% |
| 元の全PII文字のマスク率 | 27.59% | 27.08% |
| マスク文字中の元PII割合 | 88.27% | 84.12% |

元の全PII文字のマスク率は、すべての検出候補を受理したときに元の注釈文字が
何文字覆われるかを測る。カテゴリーの一致は要求しない。
PDF出力の検証や人手による受理・修正はこのベンチマークに含まない。

## 処理時間（ms、3回の代表値）

同じ端末、Python 3.11.9、GiNZA / ja-ginza 5.2.0で、各splitを3回、別プロセスで順番に測定。
各プロセスで10件を追加処理してウォームアップした後、評価対象の全件を処理した。
測定中にテストやビルドは並行実行していない。OSや他アプリの負荷は完全には固定していない。
各回の指標の中央値を記載。ダウンロード・変換・ファイル読込・スコア集計・通信・モデル読込は
検出時間に含めない。新しい入力に対する基準測定であり、別データセットとの速度の優劣比較ではない。

## 確認結果と保存先

- 全85テスト成功。文字位置・対応外タグ保持・氏名結合・改変キャッシュの拒否・
  言語別集計・ウォームアップ・過剰マスクと重複文字の集計を確認。
- 既存1,000件の精度基準はGiNZAあり・ルールのみの両方で成功。
- 日本語の3回の測定は、各回とも同じ精度とマスク範囲になった。
- 全言語validation 990件でもルールのみの測定を実行し、30言語の個別集計を確認。
- 原本・変換済みデータ・manifestは `data/benchmarks/ai4privacy-pii-masking-mini-10k/`。
- 試行別の結果・見逃し・誤検出は `build/ai4privacy/ja-validation-1.json` など。
  集約記録は `build/ai4privacy/summary.json`。入力SHA-256・エンジンSHA-256も記録。

データ本体と個々のエラーを含む結果はGitに追加しない。CIは外部ダウンロードに依存せず、
架空の小さなテストデータで取り込み・評価処理を検証する。
