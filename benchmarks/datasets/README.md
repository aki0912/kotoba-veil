# Benchmark dataset provenance

## `synthetic-v1.jsonl`

- 作成方法: `benchmarks/generate_synthetic.py`、generator version 1.0.0
- 固定seed: 20260801
- 件数: 1,000文書、1,050正解スパン
- 分布: 単一PII 750件、複数PII 100件、PIIなし150件
- entity分布: 15種類それぞれ70正解スパン
- 実在の個人情報: 含まない
- 用途: 日本語PII検出の精度比較と回帰検知
- ライセンス: リポジトリ本体のMIT License

正確な件数とファイルハッシュは `synthetic-v1.manifest.json` に固定しています。
氏名・組織名などは合成された文脈で使用していますが、一般的な文字列が偶然、実在する
名称と一致する可能性はあります。特定個人の属性を組み合わせたレコードではありません。

## `smoke.jsonl`

- 作成方法: Kotoba Veil用に作成した合成テキスト
- 実在の個人情報: 含まない
- 言語: 日本語
- 用途: スキーマ検証、回帰検知、評価パイプラインの動作確認
- ライセンス: リポジトリ本体のMIT License

このデータは小規模かつ意図的に作られたスモークセットです。

合成データは実運用ドメインの精度を完全には代表しません。外部データセットを
追加する場合は、データごとに名称、版、
取得元、取得日、利用条件、改変内容、split方法をここへ記録してください。
